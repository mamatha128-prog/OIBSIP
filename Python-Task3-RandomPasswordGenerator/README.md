# Random Password Generator

## Task 3 - Python Programming Internship

### Objective

Build a Python program that generates random passwords based on user-defined criteria.

## Features

- Allows the user to specify password length
- Minimum password length of 8 characters
- Supports uppercase letters
- Supports lowercase letters
- Supports numbers
- Supports symbols
- Requires at least 2 character types
- Validates user input
- Allows generating multiple passwords
- Simple command-line interface

## Technologies Used

- Python
- random module
- string module
