# BMI Calculator

## Task 2 - Python Programming

### Objective
Build a Python program that calculates a user's Body Mass Index (BMI) and classifies it into standard health categories.

### Technology Used
- Python
- input()
- Basic arithmetic

### Features
- Takes weight in kilograms (kg) as input
- Takes height in meters (m) as input
- Calculates BMI using the formula:
  BMI = weight / (height²)
- Classifies BMI into:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Displays BMI rounded to 2 decimal places
- Handles invalid and negative inputs

### BMI Categories

| BMI Range | Category |
|---|---|
| Less than 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25 - 29.9 | Overweight |
| 30 or above | Obese |
