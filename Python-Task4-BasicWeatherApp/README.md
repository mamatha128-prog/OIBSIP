# Basic Weather App

## Task
Python Programming - Task 4

## Objective
To build a Python application that fetches and displays real-time weather data for a user-specified location using a weather API.

## Technologies Used
- Python
- Requests
- JSON
- OpenWeatherMap API

## Features
- Enter a city name
- Display temperature in Celsius and Fahrenheit
- Display humidity
- Display weather condition
- Display wind speed
- Handles invalid city names
- Handles invalid API key
- Handles network timeout
- Rejects empty city input

## How to Run

1. Install Python.
2. Install the required package:
   `pip install requests`
3. Add your OpenWeatherMap API key locally.
4. Run:
   `python weather_app.py`
5. Enter a city name when asked.

## Note
The API key is kept private and is not included in the GitHub repository.
