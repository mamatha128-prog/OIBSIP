# Voice Assistant

## Task 1 - Python Programming

### Objective

Build a simple command-line voice assistant using Python that can understand basic voice commands and respond to the user.

### Features

- Greets the user
- Responds to basic commands
- Tells the current time
- Tells the current date
- Opens Google
- Opens YouTube
- Searches Google
- Uses text-to-speech to speak responses
- Uses speech recognition to understand voice commands
- Provides a text-input fallback if the microphone is unavailable
- Can be stopped using exit commands

### Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- datetime
- webbrowser
